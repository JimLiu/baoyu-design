# Baoyu Dashboard

Builds dashboards, KPI trackers and data stories over your CSV, TSV or JSON files and opens them in an editor that runs on your computer, whose Sources panel shows where every number comes from. Comment for the agent and refresh when the data changes. Runs locally on Node.js 22 or later.

Skills: `claude-dashboard`.

It runs on your computer, in the ChatGPT desktop app or Codex, and needs Node.js 22 or later.

Built from [baoyu-design](https://github.com/JimLiu/baoyu-design); see [how to install it](https://github.com/JimLiu/baoyu-design/blob/main/chatgpt-plugins/README.md). Terms: [LICENSE](LICENSE) and [NOTICE.md](NOTICE.md).
