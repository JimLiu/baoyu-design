# Baoyu Design System

Builds a design system from a code repository, a design tool or scratch: tokens, type, components, assets and a brand book, as files in your workspace, in a page that runs on your computer where you can browse and edit them. Baoyu Slides and Baoyu Canvas can install what it makes. Runs locally on Node.js 20 or later.

Skills: `claude-design-system`.

It runs on your computer, in the ChatGPT desktop app or Codex, and needs Node.js 20 or later.

Built from [baoyu-design](https://github.com/JimLiu/baoyu-design); see [how to install it](https://github.com/JimLiu/baoyu-design/blob/main/chatgpt-plugins/README.md). Terms: [LICENSE](LICENSE) and [NOTICE.md](NOTICE.md).
