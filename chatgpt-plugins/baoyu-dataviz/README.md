# Baoyu Dataviz

A method for charts and data visualizations in any medium, from HTML and SVG to matplotlib, plotly, d3 and Recharts: which form fits the question, a color formula with a validator, mark specs and interaction rules, so charts read as one system in light and dark themes.

Skills: `dataviz`.
