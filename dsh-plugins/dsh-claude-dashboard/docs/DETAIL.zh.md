# Claude 数据看板

给 DeepSeek Harness 加上 **claude-dashboard** 技能。让 Agent 做一个数据看板（"把这份销售 CSV 按月份和地区做成看板"），它会在工作区里把看板写成文件：一个文件夹，里面有数据集、数据集要加载的文件和页面。写完它会启动本地看板编辑器，把链接给你。

## 怎么用

- 直接用自然语言要看板、指标页、KPI 跟踪或报表，或者输入 `/claude-dashboard` 点名调用这个技能。可以给它一个 CSV、TSV 或 JSON 文件，也可以让它自己去找数据。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 来源面板（Sources）会显示每个数字是从哪里来的，还能把某个来源的数据下载成 CSV。Agent 写的改动会实时出现在页面上。
- 在页面上可以给图表、数字、表格或任何一块加评论（点评论按钮或按 C）。勾上 **Send to agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好看板，再在评论里回复你。评论也会以卡片的形式出现在对话里，点卡片上的 **View thread**（中文界面是「查看评论」）会在编辑器里打开这条评论。这个勾选框只在评论能发给 Agent 时出现；Agent 每次给你编辑器链接时都会开始等评论。重启应用后，让 Agent 再打开一次这个看板就能恢复。
- 以后要修改或刷新数据，让 Agent 修改这个看板的文件夹即可。
- 如果工作区自己带了 `claude-dashboard` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

编辑器是技能脚本在后台启动的一个本地服务（127.0.0.1），一个看板一个，只读写这个看板自己的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
