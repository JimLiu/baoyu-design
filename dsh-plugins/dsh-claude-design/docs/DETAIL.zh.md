# Claude 设计稿

给 DeepSeek Harness 加上 **claude-design** 技能。让 Agent 做一份设计（"给我们的 App 出三个落地页方向"），它会在工作区里把设计写成文件：一个文件夹，里面是 `project/canvas.json` 和每个画板一个 `.dc.html` 文件。写完它会启动本地画布编辑器，把链接给你。

## 怎么用

- 直接用自然语言要设计稿，或者输入 `/claude-design` 点名调用这个技能。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 编辑器里各个画板并排摆着，可以改文字、调每个画板的可调参数。你的修改会存回同一批文件；Agent 写的改动也会实时出现在页面上。
- 在画板上可以给任何元素加评论（点评论按钮或按 C）。勾上 **Send to agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好那个画板，再在评论里回复你。这个勾选框只在 Agent 等评论时出现；Agent 每次给你编辑器链接时都会开始等（对话里的一个后台任务）。重启应用后，让 Agent 再打开一次这份设计稿就能恢复。
- 以后要改，让 Agent 修改那个装着 `project/canvas.json` 的文件夹即可。
- 如果工作区自己带了 `claude-design` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

编辑器是技能脚本在后台启动的一个本地服务（127.0.0.1），一份设计稿一个，只读写这份设计稿自己的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
