# Claude 动画

给 DeepSeek Harness 加上 **claude-motion** 技能。让 Agent 做一段短动画（"做一段 15 秒的动画，讲清楚我们的同步是怎么工作的"、"给发布会做一个 logo 片头"），它会用代码一幕一幕地把动画写进工作区里的一个文件夹（默认是 `designs/<名字>/`，也可以指定别的）。写的时候它会启动本地 Motion 播放器，把链接给你，你可以在播放器里看着动画一点点成形。

## 怎么用

- 直接用自然语言提要求，或者输入 `/claude-motion` 点名调用这个技能。给它你自己的素材效果最好：截图、logo、品牌色、字体。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 播放器里可以播放、拖动进度。页面上的 **Continue**、**Finalize**、**Make the animation** 和 **Ask Agent** 按钮和评论一样，会把请求直接发给 Agent：对话里出现一张卡片，Agent 接着去做，对话空闲时也一样。Agent 没在等的时候（比如重启应用后、还没让它再打开这段动画），按钮会改成复制请求，你把它粘贴到对话里发出去。
- 给某个时刻留评论：点顶部栏的评论按钮进入评论模式，点画面就是评论那个时刻的那个位置，拖一下是框住一块区域，按 R 是标出一段时间。勾上 **Send to Agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好动画，再在评论里回复你。评论也会以卡片的形式出现在对话里，点卡片上的 **View thread**（中文界面是「查看评论」）会在播放器里打开这条评论。这个勾选框只在评论能发给 Agent 时出现；Agent 每次给你播放器链接时都会开始等评论。重启应用后，让 Agent 再打开一次这段动画就能恢复。
- 导出：动画下方的下载按钮会在页面里把动画编码成 MP4 或 GIF，存到下载文件夹。
- 以后要改，让 Agent 修改那个动画所在的文件夹即可。
- 如果工作区自己带了 `claude-motion` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

播放器是技能脚本在后台启动的一个本地服务（127.0.0.1），一段动画一个，只读写这段动画自己的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
