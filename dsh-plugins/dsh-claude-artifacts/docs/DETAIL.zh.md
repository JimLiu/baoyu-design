# Claude 作品

baoyu-design 各插件（Claude 幻灯片、Claude 设计稿、Claude 设计系统、Claude 数据看板、Claude 动画）共用的部分。它随每个插件一起安装，一般不用自己装。

## 做什么

- **作品页。** 在左侧栏加入 **Artifacts**（「作品」）：Agent 用这些技能打开过的所有东西，点一下就回到它的对话和编辑器。
- **评论。** Agent 打开编辑器以后，它负责等评论，所以评论上才有 **Send to Agent**。你发出的评论会叫醒 Agent，并以卡片的形式出现在对话里。

## 让它开着

关掉某个技能自己那一行，或者把技能只留给某个 Agent 预设，都不影响这一行：作品页照常工作，做过的东西还能打开。关掉这一行，侧栏就没有「作品」，评论也到不了 Agent，除非 Agent 自己等评论。

## 什么时候要自己装

只有从文件夹添加插件时才要：应用不会替这种插件安装依赖。先添加这个插件的文件夹，再添加其他插件。
