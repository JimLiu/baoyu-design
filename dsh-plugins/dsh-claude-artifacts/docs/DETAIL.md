# Claude Artifacts

What the baoyu-design plugins (Claude Slides, Claude Design, Claude Design System, Claude Dashboard, Claude Motion)
share. It comes with each of them, so you normally never install it yourself.

## What it does

- **The Artifacts page.** Adds **Artifacts** to the left sidebar: everything the agent has opened with one of these
  skills, each a click away from its conversation and editor.
- **Comments.** After the agent opens an editor, it waits for comments, so **Send to Agent** is there on a comment. What
  you send wakes the agent and shows as a card in the chat.
- **Updates.** When a new version of these plugins is out it tells you, and one click updates them.

## Keep it on

Turning a skill's own row off, or keeping a skill to one agent preset, does not touch this row: the Artifacts page goes
on working and your earlier work still opens. Without this row the sidebar has no **Artifacts**, and no comment reaches
the agent unless the agent waits for them itself.

## Installing it yourself

Only for plugins added from a folder, because the app installs no dependencies for those: add this plugin's folder
first, then the others.
