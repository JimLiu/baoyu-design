# Claude 幻灯片

给 DeepSeek Harness 加上 **claude-slides** 技能。让 Agent 做一份幻灯片（"做一份 10 页的三季度业绩汇报"），它会在工作区里把幻灯片写成文件：一个文件夹，里面是 `project/deck.json` 和每页一个 HTML 文件。写完它会启动本地幻灯片编辑器，把链接给你。

## 怎么用

- 直接用自然语言要幻灯片，或者输入 `/claude-slides` 点名调用这个技能。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 编辑器里可以放映、改字、拖动元素，导出 PDF、HTML 或 PowerPoint（.pptx）。你的修改会存回同一批文件；Agent 写的改动也会实时出现在页面上。
- 在编辑器里可以给任何元素加评论（点评论按钮或按 C）。勾上 **Send to agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好那一页，再在评论里回复你。评论也会以卡片的形式出现在对话里，点卡片上的 **View thread**（中文界面是「查看评论」）会在编辑器里打开这条评论。这个勾选框只在评论能发给 Agent 时出现；Agent 每次给你编辑器链接时都会开始等评论。重启应用后，让 Agent 再打开一次这份幻灯片就能恢复。
- 以后要改，让 Agent 修改那个装着 `project/deck.json` 的文件夹即可。
- 如果工作区自己带了 `claude-slides` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

编辑器是技能脚本在后台启动的一个本地服务（127.0.0.1），一份幻灯片一个，只读写这份幻灯片自己的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
