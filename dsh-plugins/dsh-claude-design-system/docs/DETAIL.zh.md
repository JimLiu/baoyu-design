# Claude 设计系统

给 DeepSeek Harness 加上 **claude-design-system** 技能。让 Agent 做一套设计系统（"从这个仓库的样式整理一套设计系统"、"给一家茶饮店做一套品牌规范"），它会在工作区里把设计系统写成文件：一个文件夹，里面有 `project/design-system.json`、`tokens.json`、README 品牌手册、组件预览、字体和素材。写完它会启动本地设计系统页面，把链接给你。claude-slides 和 claude-design 都可以套用它做出来的设计系统。

## 怎么用

- 直接用自然语言要设计系统，或者输入 `/claude-design-system` 点名调用这个技能。
- 打开 Agent 给的链接。桌面版里它会在右侧栏的浏览器里打开，和对话并排（设置 → 通用 → 聊天链接打开方式：**应用内侧栏**，默认就是这个）。
- 页面上可以浏览和修改设计令牌、颜色、字体样式、组件和素材。你的修改会存回同一批文件；Agent 写的改动也会实时出现在页面上。
- 可以给某个令牌、颜色、字体样式、组件、素材或章节加评论（点评论按钮或按 C）。勾上 **Send to agent** 发出去，Agent 会马上接手，对话空闲时也一样：它改好设计系统，再在评论里回复你。这个勾选框只在 Agent 等评论时出现；Agent 每次给你页面链接时都会开始等（对话里的一个后台任务）。重启应用后，让 Agent 再打开一次这套设计系统就能恢复。
- 以后要改，让 Agent 修改那个装着 `project/design-system.json` 的文件夹即可。
- 如果工作区自己带了 `claude-design-system` 技能（在 `.agents/skills/` 或 `.dsh/skills/` 里），这个工作区会用它自己那份，而不是插件里的。

## 运行方式

页面由技能脚本在后台启动的一个本地服务（127.0.0.1）提供，一套设计系统一个，只读写这套设计系统自己的文件夹。用的是桌面版自带的 Node，不需要另外安装任何东西。
